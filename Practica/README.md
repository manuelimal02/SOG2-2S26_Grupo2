# SOG2-2S26_Grupo2

**1. Crear el entorno virtual**
```bash
python -m venv venv
```

**2. Activarlo**
```bash
source venv/bin/activate
```

**3. Instalar los requerimientos** 
```bash
pip install -r requirements.txt
```

**4. Correr el script**
```bash
python ETL.py
```

**5. Desactivar el entorno virtual** 
```bash
deactivate
```
